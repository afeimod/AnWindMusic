# AnWindMusic —— AnWind 云音乐独立版

从 [AnWind](https://github.com/afeimod/AnWind) 项目中的「云音乐」应用整体移植而成的**独立安卓音乐播放器**，界面与功能对照网易云音乐 PC 版，包名 `com.anwindmusic`。

## 功能特性

### 在线音乐
- **搜索播放**：酷我音乐曲库关键词搜索（歌名/歌手/专辑），分页加载，热门关键词快捷入口
- **双搜索音源（v1.1.0）**：搜索页一键切换「酷我 / 聚合」两音源，选择自动记忆；
  聚合源为开源项目简音同款 Meting 聚合接口（api.qijieya.cn），网易云曲库直连
  （空结果自动回落酷狗），即搜即播 + 封面/歌词直链自动跟进，收藏/下载/歌词全功能通用
- **多源播放直链解析**：多个解析 API 依次回退，失败自动切换
- **歌曲下载**：MP3 下载（带进度条/失败重试/下载管理页），歌词同步下载为 .lrc
- **歌词下载**：任意歌曲可手动下载 .lrc（无需先播放）

### 歌词系统
- **四级词源回退**：酷我 → 网易云 → QQ 音乐 → LRCLIB，冷门歌/外文歌命中率高
- **3D 歌词秀**：真透视歌词墙（俯仰/偏航/纵深/行内逐字左右字体差）、KTV 逐字填色、
  当前行高亮发光、翻译显示、封面模糊背景、自定义背景图/视频/封面/光盘图片、
  非高亮歌词颜色自定义
- **双界面切换**：3D 歌词墙与黑胶唱片机两种歌词界面，点击封面/唱片即可互切，样式自动记忆。
  横屏为左右布局 —— 封面+光盘嵌合（封面右缘压住光盘中心、光盘中心圆
  半透明透出封面更真实）+ 右侧 3D 歌词墙；黑胶唱片机为左黑胶唱片 + 唱针臂、
  右侧同一套 3D 歌词墙（标贴 0.72r，黑边更窄）。
  v1.1.2 起：进度条与播放模式/上一首/播放/下一首控制条整体缩小（按钮行在上、进度条在下），
  置于两个界面的封面/唱片正下方并随主体垂直居中，页面下部完全让给歌词墙。
  v1.2.0 起竖屏优化：歌词页自动切换为「上下布局」—— 上部封面/唱片 + 紧凑控制条
  （按剩余高度自适应缩放），下部全宽 3D 歌词墙，窄屏下歌词行长/可读性大幅提升
- **智能歌词匹配**：多关键词候选（拆括号注释/拆 feat 合唱/文件名拆分），按歌名吻合度择优

### 音乐库
- **我喜欢** / **最近播放**（各 100 条记忆）
- **本地音乐**：MediaStore 全库扫描 或 仅扫描指定目录（SAF 文件夹选择 + 手动输入路径；
  v1.4.0 起目录扫描走媒体库路径过滤，无需「所有文件访问」权限）
- **下载即入库（v1.4.0）**：搜索下载的 MP3 经 MediaStore 写入公共音乐库 Music/AnWindMusic
  （免存储写权限、系统即时索引、其他播放器可见），自动加入本地曲库
- **本地真实元数据**：读取音频内真实标签（标题/歌手/专辑/时长，MediaStore/文件双模式），
  自动提取内嵌封面并磁盘缓存，列表/播放条/歌词页/通知栏直接显示原封面
- **播放队列**：顺序播放 / 单曲循环 / 随机播放三种模式
- **会话记忆**：退出后记住队列/歌曲/进度，重开无缝续播

### 独立 App 适配（相对桌面版新增）
- **纯手机布局**：底部导航栏 + 紧凑播放条，竖屏/横屏统一手机样式
- **后台持续播放**：mediaPlayback 前台服务，退后台/锁屏不中断；
  通知栏显示封面/进度 + 上一首/播放暂停/下一首/退出控制
- **锁屏与线控**：MediaSession 支持，锁屏控制、耳机/蓝牙媒体按键
- **锁屏播放保活**：MediaPlayer setWakeMode，息屏不卡顿
- **系统选择器 + 内置选择器双保险（v1.4.0）**：背景图/背景视频/封面/光盘图片优先走系统
  文件管理器（DocumentsUI，带最近/图片/视频/相册等分类侧栏）；电视/无文件管理器设备
  自动切换**应用内置选择器**（MediaStore 缩略图网格，遥控四向 + OK 选中）；
  选择结果均复制到应用私有目录，不怕授权过期。扫描目录走系统文件夹选择器
  （主存储自动换算真实路径；电视可用手动输入路径）
- **自定义视频背景（v1.2.0）**：主页与歌词页背景均可选本地视频 —— 静音循环铺底、
  等比 cover 裁剪铺满（TextureView 实现，新旧系统全兼容）、配压暗滑条保证文字可读、
  退后台/被歌词页覆盖自动暂停省电、编码不支持自动透明兜底
- **默认全屏 edge-to-edge**：内容延伸到状态栏/导航栏后面，占用刘海区域；
  交互控件经 insets 避让，不被系统栏/虚拟按键遮挡；歌词页可真全屏（隐藏系统栏，返回键恢复）
- **安卓样式同步（v1.1.2）**：播放条音量滑条/进度滑条、设置页开关等控件恢复
  Material3 标准尺寸（84x16dp 音量条等桌面版遗留小控件不再压扁滑块），观感与系统一致
- **屏幕方向设置**：自动（跟随系统）/ 竖屏 / 横屏 / 自动旋转（重力感应），即选即生效
- **简约默认封面**：深蓝渐变+音符极简封面，用于无封面歌曲占位、光盘默认盘面与歌词背景
- **自定义背景全面适配**：设置图片/视频背景后顶栏/底栏/卡片/菜单/芯片整体降透融入，文字自动加深保持可读
- **非高亮歌词颜色自定义（v1.2.0）**：歌词页非当前行、翻译行与 KTV 未唱部分的字色可自选（9 色预设，默认 #D5D5DE）
- **自适应图标**：AnWindMusic 蓝色音符 logo（圆形/方圆/主题图标遮罩全兼容）

### Android TV 适配（v1.3.0，遥控器全面支持）
- **TV 桌面入口**：manifest 声明 `LEANBACK_LAUNCHER` + 320x180 品牌横幅（`tv_banner`），
  电视桌面直接显示图标；`touchscreen` / `leanback` 特性均为 `required=false`，一个 APK 同时适配手机与电视
- **全界面焦点高亮**：新增 `Modifier.tvFocus()`（TvCompat.kt）—— 所有可交互控件（歌曲行、
  收藏/下载/词按钮、热门词与音源芯片、播放全部、加载更多、滑条、开关、色板、单选、
  输入框、导航栏、播放条、歌词页控制条、封面/唱片样式切换、逐行歌词跳转…）在遥控
  聚焦时显示品牌红描边 + 轻微放大（红底按钮用白描边），手机/平板上零影响
- **遥控四向导航与确认**：D-pad 上下左右在全部界面几何寻焦、列表/滚动区自动跟随
  焦点滚动到可视区，确认键（DPAD_CENTER/回车）即点击；滑条聚焦后左右键按步进增减
- **焦点永不丢失**：页面切换/关闭歌词页销毁了焦点元素时，底部导航栏自动把焦点还给
  当前选中项；应用启动自动聚焦搜索框（聚焦即弹系统输入法，遥控可直接输入搜索词）；
  打开歌词页自动聚焦播放/暂停键
- **返回键链修复**：歌词页真全屏 → 先退全屏；歌词页 → 关歌词；设置页 → 回到进入前页面
  （原版设置页只能杀应用退出，遥控上尤其致命）；其余场景默认返回
- **TV 恒横屏**：电视上忽略竖屏/传感器方向设置，恒为横屏；沿用横屏紧凑播放条与图标底栏
- **TV 遥控增强（v1.4.0，实测问题修复）**：
  - 滑条键控：全部滑条（设置页/播放条进度/音量）D-pad 左右键按刻度步进，100% 生效；
  - 输入框焦点逃逸：搜索框/手动输入框聚焦时上下键移出，遥控不再卡死在输入框；
  - 搜索页焦点链：首条结果按上键必回音源芯片行；首次搜索出结果自动聚焦首行（OK 直接播放）；
  - 聚合源播放修复：Meting 解析失败时按「歌手 歌名」搜酷吾兜底（旧版把网易云/酷狗 ID
    当酷吾 ID 直解必然失败），聚合歌任何网络下都能播放/下载。

### 权限最小化（v1.4.0，过手机/电视安全检测）

针对部分手机/电视安全检测提示「存在违规功能，禁止安装」的问题，本版彻底移除
三类高危声明，APK 仅保留常规媒体权限，任何厂商检测均可通过：
- 移除 `SYSTEM_ALERT_WINDOW`（悬浮窗）—— 桌面歌词功能整体下线；
- 移除 `MANAGE_EXTERNAL_STORAGE`（所有文件访问）—— 下载改 MediaStore 入库、
  目录扫描改媒体库路径过滤；
- 移除 `FOREGROUND_SERVICE_SPECIAL_USE` —— 仅保留标准 mediaPlayback 播放服务；
- `allowBackup=false`，存储权限按系统版本细分（33+ 仅媒体细分权限，写权限仅限 Android 9-）。

## 环境要求

- Android 7.0（API 24）及以上
- 首次使用按需授权：音频/图片/视频读取（本地扫描、内置选择器）、通知（Android 13+ 播放控制）
- **无任何高危权限**：不申请悬浮窗、所有文件访问等「违规功能」类权限，
  可正常通过各手机/电视厂商安全检测与安装检测

## 构建方式

### 方式一：GitHub Actions 手动构建（推荐）

本项目自带手动触发的构建工作流（`.github/workflows/build.yml`）：

1. 把本项目推送到你的 GitHub 仓库
2. 打开仓库 → **Actions** 标签页 → 左侧选择 **Build AnWindMusic APK**
3. 点击 **Run workflow**，选择构建类型（`release` / `debug` / `both`）→ 运行
4. 构建完成后在该次运行页面底部 **Artifacts** 下载 APK

> release 构建使用 CI 现场生成的正式 keystore 签名（V1+V2+V3），可直接安装到任何
> Android 7.0+ 设备，不会被系统标记为 testOnly。如需固定自己的签名，可在
> `app/build.gradle.kts` 中配置 Secrets 引入自己的 keystore。

### 方式二：本地构建

```bash
git clone <本仓库> AnWindMusic
cd AnWindMusic
./gradlew assembleRelease   # 需要 JDK 17+，Android SDK 34
# 产物：app/build/outputs/apk/release/app-release.apk
```

> 本地未配置 release keystore 时，release 包会回退 debug 签名（仅适合测试）。

## 技术栈

- Kotlin 1.9.25 + Jetpack Compose（BOM 2024.06.00，Material3）
- AGP 8.5.2 / Gradle 8.7 / compileSdk 34 / minSdk 24 / targetSdk 34
- 播放引擎：android.media.MediaPlayer（流媒体 + 本地），进程级单例
- 网络：HttpURLConnection + org.json（零第三方网络/图片库，封面自实现内存缓存）
- 通知与锁屏：androidx.media（MediaSessionCompat + MediaStyle）
